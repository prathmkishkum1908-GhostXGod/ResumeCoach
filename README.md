If You Want to Run the main.py in windows, Steps Is:
1. Create a Gorq API Key.
2. Save All Files in one Folder.
3. Save index.html in another Folder Named 'static'.
4. Then in All Files Folder do Right click and click Open in Terminal.
5. Type 'uvicorn main:app --reload' in Terminal
6. After That in Terminal Copy 'http://127.0.0.1:8000' in Browser.
7. And You Good To Go
